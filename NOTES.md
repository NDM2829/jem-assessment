# Assessment notes

**Data assumptions.** I count local clock-in/out duration, without break deductions or pay multipliers, towards a Monday–Sunday total **strictly above 55 hours**. Each shift belongs wholly to its start date; an earlier end time means overnight, under 24 hours. This matches the reference accounting but can move Sunday-night hours between calendar weeks. Wednesday inputs stop at Thursday 00:00. Missing durations are estimated from earlier shifts, kept separate from observed hours; overlaps remain suspect, without repair. This preserves the reference policy, not verified truth. Only complete, clean recorded weeks supply outcome labels; 171 uncertain employee-weeks were excluded from the main comparison. The current register is assumed historically static because effective dates are absent. No current records means unknown risk, not zero risk. Payroll is unused; the weekly summary is not independent truth. Client requests, manager instructions and approval are distinct. Hours after 45 are associated with shift notes, not proven caused or billable. The [assumption history](evidence/assumption_log.md) preserves details and superseded choices, including the first reference week's hindsight reconstruction.

**Note-sorting check.** Frozen `notes-1.0` rules agreed with one reviewer's exact-text labels on **93/100 random notes** and **18/20 targeted challenges** ([labels](evidence/note_validation_review_completed.csv), [metrics](analysis/evidence/note_validation_notes-1.0.json)). Five disagreements concerned approval being labelled as a client request; the rules require an explicit request. Three spelling variants were missed, and “Clint” was mistaken for “client.” I kept those disagreements visible. The random frame excluded 170 notebook examples; targeted results are not population accuracy. One reviewer's labels are not adjudicated truth, and the review process was not independently observed.

**What learning adds, and how I would test it.** Correlated hours already learns from earlier personal and peer weeks: how Wednesday hours relate to the rest of the week. It assumes a particular distribution; note sorting uses fixed rules. A supervised model could learn nonlinear relationships between work patterns and breaches; a text model could learn spelling and language context that the rules miss. Neither can recover an unrecorded cause. With roughly 200 people, I would freeze features, method and threshold before forecasting newly completed weeks, using only Wednesday-available inputs. I would avoid random employee-week splits, report F2, recall, false alerts, calibration and weekly workload against the same naive baseline, and account for repeated employees in uncertainty estimates. Uncertain outcomes need resolution, not assumed non-breaches. Testing transfer to new people would additionally require held-out employees. The existing replay informed development and is not independent validation; revised note rules need fresh, independently labelled notes.
